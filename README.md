# Python-Start

A collection of basic Python scripts for learning and practice.

## Overview

This repository contains fundamental Python scripts demonstrating core programming concepts and techniques.

## Contents

- **main.py** - Examples of lambda functions, list filtering, mapping, and dictionary sorting

## Scripts Included

### main.py
Demonstrates the following Python concepts:
- **List Comprehensions** - Creating lists using concise syntax
- **Lambda Functions** - Anonymous functions for quick operations
- **Filter Function** - Filtering list elements based on conditions
- **Map Function** - Applying functions to list elements
- **Sorting** - Sorting lists and dictionaries
- **While Loops** - Iteration with conditions

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/riteshp1584/Python-Start.git
   cd Python-Start
   ```

2. Run any script:
   ```bash
   python main.py
   ```

## Requirements

- Python 3.x
